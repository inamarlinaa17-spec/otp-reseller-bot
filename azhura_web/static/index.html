📲 Order OTP — nomor virtual
  1. Isi saldo dulu lewat Deposit (QRIS manual/otomatis).
  2. Buka Order OTP → pilih server → pilih layanan & negara.
  3. Konfirmasi harga, lalu bayar dari saldo.
  4. Nomor muncul; pakai untuk daftar aplikasi. Tunggu OTP di Riwayat (auto refresh).
  5. Selesai / batal sesuai status di Riwayat.
🚀 SMM PANEL — followers, likes, views
  1. Pastikan saldo cukup.
  2. Buka SMM PANEL → pilih platform (IG, TikTok, dll).
  3. Pilih jenis layanan & jumlah, isi link target (profil/post).
  4. Order diproses otomatis; pantau status di riwayat SMM.
💎 APK PREMIUM — Netflix, Canva, Gemini, dll
  1. Buka APK PREMIUM → pilih kategori / produk.
  2. Pilih paket/varian yang tersedia.
  3. Bayar dari saldo; detail akun/akses muncul setelah order sukses.
  4. Simpan data akun; cek lagi di riwayat jika perlu.
📧 BELI GMAIL — akun siap pakai
  1. Buka BELI GMAIL → lihat stok & harga.
  2. Order sesuai kebutuhan; saldo terpotong otomatis.
  3. Data akun ditampilkan setelah berhasil — segera simpan.
💳 Deposit — isi saldo
  1. Buka Deposit → pilih QRIS Manual atau Otomatis.
  2. Masukkan nominal → buat tagihan → bayar sesuai instruksi.
  3. Saldo bertambah setelah pembayaran terverifikasi.
🤝 RESELLER — bot & web sendiri
  1. Buka RESELLER → buat bot lewat token @BotFather.
  2. Isi Contact CS agar bot aktif, atur margin.
  3. Salin Link Web Reseller untuk promosi ke pembeli.
  4. Pantau user & withdraw margin di dashboard reseller.
